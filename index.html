Heartland Dev Bot

A private automation tool. It is not a public service and has no sign-up.

Heartland Dev Bot is a small program that its developer runs on their own computer to help maintain one small-business website. It reads website change requests that arrive by email from one approved sender, prepares the code change for review, and replies with a short summary and preview screenshots. A person approves every change before it is published.

What it uses Google for

  • Gmail: to read change requests from the one approved sender, to reply in the same email thread, and to label messages it has handled.
  • Google Drive: to share preview screenshots through a link. It only sees the folders it creates itself, and it removes each folder once a change is approved.

The only Google account it uses is its developer's own. It doesn't access anyone else's Google account.
